# Модуль: `:core:di`

Центральный модуль конфигурации внедрения зависимостей на базе библиотеки Koin.

---

## 1. Зона ответственности

* Предоставление точки входа для инициализации графа зависимостей (`initKoin`).
* Агрегация Koin-модулей фичей (`rootModule`, `homeModule`, `profileModule`) и инфраструктуры.
* Обеспечение мультиплатформенного запуска DI на Android (`androidContext`) и iOS (`initKoinIOS`).

---

## 2. Публичные компоненты

* **`initKoin(appDeclaration: KoinAppDeclaration)`:** Основная функция сборки графа DI, вызываемая на старте каждого приложения.

---

## 3. Зависимости

### Зависит от:
* `:features:root`
* `:features:home`
* `:features:profile`
* `io.insert-koin:koin-core`

---
