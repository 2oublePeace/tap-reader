# Модуль: `:features:home`

Фича главного экрана приложения TapReader (библиотека книг и материалов, быстрый возврат к текущему чтению).

---

## 1. Зона ответственности

* Отображение списка книг, статей и материалов пользователя, а также текущего прогресса чтения.
* Обработка пользовательских действий на главном экране.
* Чистая MVI-архитектура без утечки Compose-зависимостей в интерфейс компонента.

---

## 2. Публичный контракт (`api/`)

* **`HomeComponent`:** Pure Kotlin интерфейс с реактивным `val state: Value<HomeState>`, методом `fun onIntent(intent: HomeIntent)` и `HomeComponent.Factory`.
* **`HomeState`:** Иммутабельная (`@Immutable`) модель UI-состояния главного экрана.
* **`HomeIntent`:** Sealed-интерфейс пользовательских событий главного экрана.
* **`HomeScreen`:** Stateful Composable-контейнер для встраивания в родительский навигационный граф.
* **`homeModule` (`api/di/`):** Koin-модуль с регистрацией фабрики компонента.

---

## 3. Внутренняя реализация (`impl/`, internal)

* **`HomeComponentImpl`:** Оркестрация жизненного цикла Decompose и управление состоянием.
* **`HomeContent`:** Stateless Composable-верстка, изолированная для `@Preview` и тестов.

---

## 4. Зависимости

### Зависит от:
* `:core:decompose`

### От него зависят:
* `:features:root` (для встраивания в стек навигации)
* `:core:di` (для регистрации `homeModule` в графе)
